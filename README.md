# Object-Oriented Programming Lab

This repository contains my **Object-Oriented Programming (OOP) Lab** work, including lab tasks, practice programs, and programming exercises completed during the course. It covers fundamental OOP concepts and their implementation through practical coding in C++.

**Topics include:**

* Classes and Objects
* Constructors and Destructors
* Encapsulation
* Inheritance
* Polymorphism
* Abstraction
* Operator Overloading
* Composition and Aggregation
* Other OOP concepts and lab exercises
