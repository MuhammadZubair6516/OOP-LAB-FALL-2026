## 📌 Overview

This laboratory session introduces the fundamental concepts of **Classes and Objects in C++**. The lab focuses on creating classes, defining objects, controlling access to class members, implementing constructors, and defining member functions.

---

## 🎯 Objectives

By completing this lab, the following concepts are covered:

* Explain the concept of a **class** as a blueprint for creating objects.
* Create and work with **objects** from a class.
* Differentiate between a **structure (`struct`)** and a **class** in C++.
* Understand and apply **access specifiers**:

  * `public`
  * `private`
  * `protected`
* Define member functions **inside and outside** the class.
* Use the **scope resolution operator (`::`)** to define member functions outside the class.
* Understand the purpose of **constructors**.
* Implement:

  * Default constructors
  * Parameterized constructors

---

## 🧠 Topics Covered

### 1. Classes

A class is a blueprint that defines the data and behavior of objects.

### 2. Objects

Objects are instances of a class. Multiple objects can be created from the same class.

### 3. Access Specifiers

C++ provides different access levels for class members:

| Access Specifier | Accessibility                                   |
| ---------------- | ----------------------------------------------- |
| `private`        | Accessible only inside the class                |
| `public`         | Accessible from outside the class               |
| `protected`      | Accessible inside the class and derived classes |

### 4. Member Functions

Member functions define the behavior of objects. They can be written:

* Inside the class body
* Outside the class using the **scope resolution operator (`::`)**

### 5. Constructors

A constructor is a special member function that is automatically called when an object is created.

Two important types covered in this lab are:

* **Default Constructor**
* **Parameterized Constructor**
