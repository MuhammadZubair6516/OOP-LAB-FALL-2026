# OOP Lab 01 — C++ Fundamentals

**Course:** Object Oriented Programming
**Course Code:** CL-1004
**Lab:** 01
**Semester:** Spring 2026
**Language:** C++

## 📌 Lab Overview

This lab introduces the fundamental concepts of C++ programming, including console input/output, data types, arrays, and pointers. The lab focuses on building a strong foundation for understanding and writing C++ programs.

## 🎯 Objectives

* Understand the basic structure of a C++ program.
* Use `cin` and `cout` for console input and output.
* Work with different C++ data types.
* Declare, initialize, and manipulate arrays.
* Understand pointers and memory addresses.
* Use the address-of (`&`) and dereference (`*`) operators.
* Practice basic C++ programming through different problems.

## 📝 Lab Tasks

### Q1 — Student Information

Write a C++ program that displays:

* Name
* Roll Number
* Department
* Semester

using `cout`.

### Q2 — Arithmetic Operations

Take two integers from the user and display their:

* Sum
* Difference
* Product
* Quotient

### Q3 — Basic Data Types

Declare and initialize variables using:

* `int`
* `float`
* `double`
* `char`
* `bool`
* `string`

Then display their values.

### Q4 — Array Elements

Take five integer values into an array and display:

* First element
* Third element
* Last element

### Q5 — Largest Array Value

Store five integer values in an array and find the largest value.

### Q6 — Pointers

Take an integer from the user and demonstrate:

* Its value
* Its memory address
* Pointer value
* Dereferenced value

The six tasks above are the exercises specified in the Lab 01 manual.
